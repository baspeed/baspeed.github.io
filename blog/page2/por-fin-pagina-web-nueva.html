Por fin, página web nueva

Por djnacho24 Julio, 2020

Supongo que lo habréis notado si visitáis con relativa frecuencia el site oficial de BASpeed. Ya no tiene el aspecto de un blog normal y cualquiera, y tiene el aspecto de una página mucho más profesional y bonita visualmente.

Uno de los cambios que quería acometer desde hace mucho era cambiar radicalmente la página web de BASpeed. Tener una página de producto, y no un blog o un CMS como Joomla o Wordpress corriendo por debajo sin ofrecer una imagen de producto, que es lo que yo quería. A partir de ahora si vamos a tener esa imagen, y por supuesto una página web como Dios manda, que ya era hora.

También he cambiado el blog de desarrollo de BASpeed. Ahora ya no está realizado con Publii (que era el anterior CMS usado para el blog), sino que es un sistema integrado con la página principal del site. De esa forma se puede ofrecer el mismo aspecto que este, y al mismo tiempo ofrecer contenido como si fuera un blog. De hecho, esta entrada y todas las anteriores (migradas de Publii a este nuevo sistema) pertenecen al nuevo blog.

Por si alguien tiene curiosidad, este site y el nuevo blog han sido creados usando bootstrap studio, de forma que los más avezados ya sabéis que este site y su blog utilizan el framework de bootstrap para funcionar.

Espero que os gusten los cambios ya que mi intención era mejorar por mucho todos los anteriores sitios web de BASpeed, y creo que lo he conseguido 😉. Un saludo a todos 😊
